# Как устроен код

## Главная идея

**Весь экран строится из кода.** В сценах почти ничего нет: камера и один стартовый компонент. Поле, HUD, кнопки, всплывающие окна и карта создаются скриптами во время игры. Картинки и звуки скрипты берут по короткому ключу из каталога `GameArt` (например, `"cat_0"`, `"ui_play"`, `"mouse_idle"`).

Почему так:
- Ничего не нужно связывать в инспекторе, и нечему «отвалиться».
- Чтобы заменить картинку, достаточно положить новый PNG по тому же пути.
- Если картинки нет, игра не падает, а рисует заглушку (цветной прямоугольник или текст).

## Сцены

| Сцена | Стартовый компонент | Что происходит |
|---|---|---|
| `Scenes/Splash.unity` | `SplashScreen` | Постер «Кузя и Нафаня» (целиком, по бокам размытая копия), кнопка «Играть». Музыки нет |
| `Scenes/Game.unity` | `GameController` | Вся игра: карта уровней, поле, окна |

Сцены создаются командой меню **Kuzya → Setup Scenes** (`Editor/ProjectSetup.cs`).

## Скрипты

### `Assets/Scripts/Core`: правила, без отображения

| Файл | Отвечает за |
|---|---|
| `LevelGen.cs` | Генератор уровней. `Build(level)` → `LevelDef` (форма поля, ходы, преграды, пена, молоко, мышка, задания). Константы появления механик, `Difficulty`, `MovesFactor`, послабления после проигрышей, расписание событий (`IsEventLevel`) |
| `Progress.cs` | Сохранение в `PlayerPrefs`: текущий уровень, монеты, запас бустеров, цены, открытые сундуки (`ChestOpened`, `PendingChest`) |
| `AudioManager.cs` | Музыка и звуки: громкость (сохраняется), приглушение музыки на экране победы, `Play("ключ", громкость)` |
| `GameArt.cs` | Каталог «ключ → спрайт/звук/шрифт» (`Resources/GameArt.asset`) + «видимая область» каждого спрайта, чтобы котики на холстах разного размера выглядели одинаково |
| `Loc.cs` | Все тексты интерфейса (только русский) |

### `Assets/Scripts/Game`: всё на экране

| Файл | Отвечает за |
|---|---|
| `GameController.cs` | «Режиссёр» игрового экрана: HUD (панель с ходами, 3 медальона заданий, баланс), бар бустеров, очки, монеты, проверка победы/проигрыша, все окна (задания уровня, пауза, настройки, победа/проигрыш, сундук, «Знакомься!»), анимированные надписи «Комбо» и «Попался!», значок сундука на экране игры |
| `Board.cs` | Поле: ввод (свайп/нажатие), поиск рядов, спецкотики и их комбинации, каскады и падение, преграды, пена, молоко, мышка, подсказка, перемешивание. Сообщает `GameController` о событиях |
| `Piece.cs` | Одна фишка в клетке: котик (обычный/спец, с коробкой/клубком/мятой), рыбка, ваза, ведро молока. Её картинка, «злое» лицо, покачивание |
| `Kit.cs` | Общие помощники: анимации-корутины (`Tween`, easing), процедурные спрайты-заглушки, `FitSprite` (вписывает спрайт по видимой части). Там же класс `FX`: все эффекты (лопанье котиков, лучи, взрывы, радуга, охотник, осколки, пена, брызги молока, полёт иконки в HUD, тряска) |
| `UIKit.cs` | Фабрика интерфейса: холсты, картинки, текст, кнопки-картинки (с нажатым состоянием), текстовые кнопки, слайдеры. Базовое разрешение 1080×1920 |
| `LevelMap.cs` | Бесконечная карта уровней («дорожка» снизу вверх): узлы уровней, маркер с котиками, декорации, сундуки каждые 5 уровней, кнопки «Играть» и «К моему уровню» |
| `Background.cs` | Фон из трёх окрашиваемых кодом слоёв (градиент, узор, боке) и 6 цветовых тем |
| `SplashScreen.cs` | Заставка |

### `Assets/Scripts/Editor`: инструменты в редакторе

| Файл | Отвечает за |
|---|---|
| `GameArtBuilder.cs` | Собирает каталог `GameArt` из файлов. Список «ключ → путь» и звуков (`SoundFiles`). Правила импорта картинок и звуков (см. [ASSETS.md](ASSETS.md)). Меню **Kuzya → Rebuild Art Catalog** |
| `DevTest.cs` | Автоматические проверки из редактора: бот-симулятор уровней, клики, серии скриншотов (см. [DEV_TOOLS.md](DEV_TOOLS.md)) |
| `Capture.cs` | Скриншот игры в разрешении телефона: **Kuzya → Capture Screenshot** |
| `ProjectSetup.cs` | Создаёт сцены и базовые настройки проекта |

## Как проходит уровень

```
Карта (LevelMap) ── «Играть» ──► GameController.StartLevel(N)
                                   │  LevelGen.Build(N)          ← уровень из номера
                                   │  Board.Setup(def)           ← поле, преграды, пена, ведро, мышка
                                   │  цели преград = сколько реально встало на поле
                                   ▼
                     [Знакомься!] ► окно «Задания» ► игра
                                   │
      Board: свайп ► ряды ► Execute (лопанье, удары по преградам, пена, молоко, поимка мышки)
             ► Gravity (падение) ► ResolveLoop (каскады) ► EndMove (мята, высыхание молока,
               ход мышки, перемешивание) ► MoveResolved
                                   │
      GameController: очки, монеты, задания в HUD, «Комбо» ► CheckEnd
                                   │
               все задания ✓ ─► Win(): мышка убегает, награда, экран победы, сундук
               ходы = 0      ─► Lose(): проигрыш засчитан, экран «Ходы закончились» (+5 ходов за монеты)
```

### События поля (`Board` → `GameController`)

| Событие | Когда |
|---|---|
| `MoveCommitted` | ход начался (минус ход) |
| `CascadeStep(step, runs)` | очередная волна каскада (очки, монеты за глубокий каскад) |
| `CatCleared(color, pos)` | убран обычный котик (задание «собрать цвет») |
| `GoalHit(type, pos)` | убрана преграда / лопнула пена / доставлена рыбка |
| `Bonus(points)` | очки за преграды |
| `SpecialCleared` / `PowerUpCleared` | котики, убранные спецкотиком или бустером |
| `MilkCoin(pos)` | котик слизал молоко (x2, +1 монета) |
| `MouseSteal` (функция) | мышка просит монетку: контроллер списывает её с баланса и отвечает, откуда она летит |
| `MouseCaught(pos, coins)` | мышку поймали: «Попался!» и награда |
| `MoveResolved(cleared)` | ход закончился (комбо-баннер, проверка конца) |

## Сохранение (`PlayerPrefs`, префикс `Kuzya.`)

| Ключ | Что |
|---|---|
| `Kuzya.Level` | следующий непройденный уровень |
| `Kuzya.Balance` | монеты |
| `Kuzya.PowerUp.<тип>` | запас бустеров |
| `Kuzya.Chest` | номер последнего открытого сундука (5, 10, …) |
| `Kuzya.Losses.<N>` | проигрыши подряд на уровне N (послабления) |
| `Kuzya.Met.<id>`, `Kuzya.MetBase` | какие карточки «Знакомься!» уже показаны |
| `Kuzya.MusicVolume`, `Kuzya.SfxVolume` | громкость |

`Progress.SAVE_VERSION`: если увеличить это число, при следующем запуске прогресс сотрётся (для тестовых сборок).

## Слои отрисовки (sortingOrder)

| Порядок | Что |
|---|---|
| −100 … −80 | фон |
| 1–2 | подложка и клетки поля |
| 4 | пена |
| 5 | лужи молока |
| 10 (18–20 при обмене) | котики |
| 30–31 | мышка и её монетки |
| 60+ | эффекты (`FX.FxOrder`) |
| холст UI 30, холст Popups 100 | HUD и окна |
