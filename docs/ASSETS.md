# Картинки и звуки

## Каталог `GameArt`

Код не ссылается на файлы напрямую. Он просит картинку по ключу: `GameArt.I.S("mouse_idle")`, звук тоже по ключу: `AudioManager.Play("mouse_hop")`. Соответствие «ключ → файл» задаётся в `Assets/Scripts/Editor/GameArtBuilder.cs`:

```csharp
{ "mouse_idle", "Assets/Sprites/Mouse/mouse_idle.png" },
{ "combo_1", "Assets/Combos/soft/Combo.png|Assets/Combos/Combo.png" },   // через | — запасные варианты
```

Из этого списка редактор собирает файл `Assets/Resources/GameArt.asset`. Для каждой картинки он дополнительно считает её **видимую область** (где пиксели не прозрачные). По ней `Kit.FitSprite` масштабирует спрайты, поэтому котики с разным прозрачным полем вокруг выглядят на поле одинакового размера.

Каталог пересобирается сам при импорте картинки из списка. Вручную: **Kuzya → Rebuild Art Catalog**.

### Как добавить или заменить картинку

1. Положи PNG с прозрачным фоном в нужную папку (`Assets/Sprites/…`, `Assets/ui/…`, `Assets/Combos/…`, `Assets/Level-menu/…`).
2. Если это новая картинка, добавь строку `{ "ключ", "путь" }` в `GameArtBuilder.cs`. Если заменяешь старую, просто перезапиши файл с тем же именем.
3. **Kuzya → Rebuild Art Catalog**.
4. В коде используй ключ.

### Как добавить звук

1. Положи `.mp3` в `Assets/Sounds/`.
2. Добавь в словарь `SoundFiles` в `GameArtBuilder.cs`: `{ "ключ", "имя_файла_без_mp3" }`.
3. **Kuzya → Rebuild Art Catalog**.
4. В коде: `AudioManager.Play("ключ", громкость)`.

## Правила импорта (`GameArtBuilder.OnPreprocessTexture` / звук)

### Картинки

- Все PNG в папках с картинками импортируются как одиночный Sprite без mipmap.
- Максимальный размер текстуры:
  - **2048**: большие картинки (заставка, фоны, окна, котики экрана победы/проигрыша);
  - **512**: мелкие эффекты (`/fx/`, конфетти, обломки комбо, капли);
  - **1024**: всё остальное.
- **Стороны кратны 4.** Иначе Android не может сжать текстуру, она хранится несжатой (RGBA32) и раздувает APK. Скрипт `tools/artsize.py` уменьшает картинки до нужного размера и дополняет прозрачными пикселями до кратности 4. Оригиналы он сохраняет в `_art_originals/` (эта папка не в git). После этой обработки картинки стали занимать ~52 МБ вместо ~180 МБ.

```bash
cd <папка проекта>
python3 tools/artsize.py          # показать, сколько файлов нужно поправить
python3 tools/artsize.py --apply  # поправить (оригиналы → _art_originals/)
```

### Звуки

| Тип | Настройки |
|---|---|
| Музыка (`Game.mp3`, `menu.mp3`) | Streaming, Vorbis 50%: не грузится в память целиком |
| Эффекты (все остальные) | Decompress On Load, Vorbis 60%, моно |

Если настройки не применились, их можно выставить через `AudioImporter` и `SaveAndReimport()` (так делалось для новых звуков).

## Как готовились картинки

Картинки сгенерированы по текстовым описаниям и обработаны скриптами Python (PIL / scipy / rembg):
- **Зелёный фон → прозрачность** (хромакей): `alpha = clip(1 − (g − max(r,b) − 25) / 80)`, плюс подавление зелёной каймы `g = min(g, max(r,b) + 10)`.
- **Свечение на чёрном фоне:** прозрачность по яркости.
- **Листы с несколькими картинками** нарезались по сетке или по подписям.
- **Размеры** приводились к кратным 4 (`tools/artsize.py`).
