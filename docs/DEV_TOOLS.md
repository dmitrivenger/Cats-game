# Инструменты разработчика

Все инструменты работают только в Unity-редакторе и в сборку на телефон не попадают (папка `Editor`).

## Меню Kuzya

| Пункт | Что делает |
|---|---|
| **Rebuild Art Catalog** | Пересобирает `Resources/GameArt.asset` из файлов картинок и звуков |
| **Capture Screenshot** | Сохраняет кадр игры 1080×1920 в `_claude_tmp/Screenshots/capture.png` |
| **Setup Scenes** | Создаёт сцены Splash и Game и прописывает их в список сборки |

## `DevTest`: автоматические проверки (в режиме Play)

Методы вызываются из кода редактора (например, через Unity MCP `execute_code`). Все они статические.

| Метод | Что делает |
|---|---|
| `Buttons()` | Список кнопок на экране |
| `Click("btn_…")` | Нажать кнопку по имени (`btn_ui_play`, `btn_Понятно!`, `btn_map_chest`, …) |
| `Move()` | Сделать один ход (бот выбирает первый подходящий) |
| `State()` | Текст на экране + состояние поля |
| `Shot("имя")` | Скриншот в `_claude_tmp/Screenshots/имя.png` |
| `MoveAndShoot`, `ClickAndShoot`, `TapAndShoot` | Действие + серия скриншотов в заданные моменты (сек.) |
| `ResultAndShoot(win, …)` | Открыть экран победы/проигрыша и снять его анимацию |
| `ComboAndShoot(tier, …)`, `ComboFrames` | Показать надпись «Комбо» уровня 1–4 и снять по кадрам |
| `CaughtAndShoot(reward, …)` | Показать «Попался!» и снять по кадрам |
| `Sim(from, to, runs, smart, speed)` | **Бот-симулятор баланса** (ниже) |

Отладочные методы поля: `Board.DebugSmartMove`, `Board.DebugTap(x, y)`, `Board.DebugMakeSpecial(x, y, тип, ряд)`, `Board.DebugDump()`.

### Бот-симулятор `DevTest.Sim`

Проигрывает уровни с `from` по `to`, каждый `runs` раз, на ускоренном времени (`speed`) и без звука. Работает без бустеров и без послаблений. Умный бот (`smart = true`) выбирает ход, который больше всего продвигает задания (приоритет рыбкам, преградам, спецкотикам). Результат пишется в `_claude_tmp/sim.txt`:

```
level  run  win  movesLeft  movesUsed  coins  goals
22     0    1    3          18         16     Vase:7/7 Mint:1/1 Foam:8/8
```

После прогона уровень и баланс игрока восстанавливаются.

Важно: Unity должен быть активным окном на экране, иначе редактор не обновляет кадры и симуляция стоит. Зависший ход определяется по числу кадров, а не секунд, чтобы блокировка экрана не давала ложных «зависаний».

## Проверка баланса без игры

Генератор уровней детерминирован, поэтому можно посмотреть параметры любого уровня сразу:

```csharp
var d = LevelGen.Build(27);
// d.moves, d.goals (type, target), d.foam, d.fish, d.milk, d.mouse, d.shape …
```

Так проверялось, например, расписание событий (молоко / мышка каждые 3 уровня) и как меняются уровни после 0…9 проигрышей.
