# Purrade: Cat Match (Кузя и Нафаня)

Мобильная 2D-игра «три в ряд» с котиками для Android, сделанная в Unity. Готовится к выпуску в Google Play (разработчик Venger Studios).

Игрок меняет местами соседних котиков, собирает ряды из трёх и больше одинаковых и выполняет задания уровня за ограниченное число ходов. Уровни бесконечные: каждый генерируется из своего номера, поэтому уровень N всегда одинаковый, в том числе при повторе.

## Как открыть проект

1. Установи **Unity Hub** и Unity **6000.3.20f1** с модулем **Android Build Support** (вместе с OpenJDK и Android SDK/NDK).
2. Склонируй репозиторий и в Unity Hub нажми **Add → Add project from disk**, указав папку репозитория.
3. Первое открытие займёт несколько минут: Unity заново создаст папку `Library/`, она не хранится в git.
4. Открой сцену `Assets/Scenes/Splash.unity` и нажми ▶ Play. Игра стартует с заставки, потом открывается карта уровней.

Если картинки отображаются серыми квадратами, запусти в меню **Kuzya → Rebuild Art Catalog**. Эта команда пересобирает каталог картинок и звуков (`Assets/Resources/GameArt.asset`).

## Как собрать сборку для Google Play

1. **File → Build Profiles**, платформа **Android**. В списке сцен по порядку: `Scenes/Splash`, затем `Scenes/Game`.
2. Включён **Build App Bundle (AAB)**. Подпись: ключ `purrade.keystore` (alias `purrade`). Сам ключ и пароль в репозитории не хранятся.
3. Перед каждой новой загрузкой в Play Console увеличить **Bundle Version Code**.
4. **Build** → файл `.aab` загрузить в Play Console (Internal / Closed testing).
5. Перед публичным запуском: в `Game/Ads.cs` поставить `TestMode = false`.

Прогресс игрока (уровень, монеты, бустеры, открытые сундуки) хранится в памяти телефона (`PlayerPrefs`). Если ставить новую сборку поверх старой, прогресс сохраняется.

## Что где лежит

```
Assets/
  Scripts/
    Core/        правила без картинок: генератор уровней, прогресс, звук, каталог картинок, тексты
    Game/        всё, что на экране: поле, HUD, всплывающие окна, карта, эффекты, заставка
    Editor/      инструменты для Unity-редактора: сборка каталога, тестовый бот, скриншоты
  Scenes/        Splash.unity (заставка) и Game.unity (игра)
  Resources/     GameArt.asset: каталог «ключ → картинка/звук», собирается автоматически
  Sprites/       котики, преграды, эффекты, пена, молоко, мышка, фоны
  ui/            интерфейс: панель HUD, кнопки, окна, экран победы/проигрыша, сундук
  Combos/        слои анимированных надписей «Комбо» и «Попался!»
  Level-menu/    картинки карты уровней
  Sounds/        музыка и звуки (mp3)
  Fonts/         шрифты
Packages/        список пакетов Unity
ProjectSettings/ настройки проекта (Android, пакет, иконка, качество)
tools/           вспомогательные скрипты для обработки картинок
docs/            подробная документация (см. ниже)
```

## Не хранится в репозитории

- `Library/`, `Temp/`, `Logs/`, `UserSettings/`: Unity создаёт их сам.
- `_art_originals/`: полноразмерные оригиналы картинок до сжатия (~120 МБ), хранятся только локально.
- `_claude_tmp/`: скриншоты и логи тестов.
- Собранные `.apk`.
